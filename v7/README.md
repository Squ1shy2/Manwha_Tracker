# Manhwa Tracker v7 — Cloud development

This directory contains the new cloud-edition application work. The existing repository-root v6.4 application and GitHub Pages site remain unchanged.

## Goals
- Email/password accounts through Supabase Auth
- Guest mode, with a local empty library
- Account-specific cloud libraries and offline-first synchronization
- Safe conflict detection and explicit recovery
- Import/export compatibility with v6.4
- Expandable AniList and MangaUpdates verification providers

## Status
Development workspace initialized. Not yet deployed.
