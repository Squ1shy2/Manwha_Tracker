# Manhwa Tracker PWA

Upload every file in this folder to the root of a GitHub repository.

Required files:
- index.html
- manifest.webmanifest
- service-worker.js
- icon-192.png
- icon-512.png
- apple-touch-icon.png

The app works offline after it has been opened successfully at least once.
Live status checks and external manhwa/source links still require internet.
Chapter progress, status choices, links, and notes are stored in the browser on each device.
Use Export/Import to move data between devices.
